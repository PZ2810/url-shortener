How the code is made

Every link gets a number from the database. That number is written in base 62 (0-9, a-z, A-Z) so it stays short.

Character Value Place Adds
Code: 21

What happens when a link is opened

A sequence designed for speed under high read traffic.

  1. 1 The browser asks for /21.
  2. 2 Flask looks for 21 in Redis.
  3. 3 Found: skip to step 5.
  4. 4 Not found: Flask reads the link from PostgreSQL and saves it in Redis.
  5. 5 Flask answers with a 302 redirect to the original address.

API

Standard JSON endpoint designed for automation and integration.

curl -X POST https://short.pranavcloud.in/shorten \
  -H "Content-Type: application/json" \
  -d '{"url": "https://example.com"}'
Limit
10 requests per 60 seconds per IP.
Redirect
302 Found with original destination in Location header.
Storage
PostgreSQL relational store, cached in Redis in-memory.
